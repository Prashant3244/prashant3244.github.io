1. Introduction & Core Architecture

SheetPulse ("we", "our", or "the extension") is a browser productivity extension designed to extract, clean, and export tabular HTML data into CSV, TSV, JSON, and Excel formats. We operate on a Strict Client-Side Processing Architecture. All table detection, DOM parsing, coordinate matrix calculation, and file conversions occur 100% locally in your web browser.

2. Data Collection & Handling Practices

SheetPulse does NOT collect, harvest, monitor, or transmit your web browsing activity, webpage contents, extracted table data, or personal files to any external server.

  • Extracted Table Data: Processed entirely in browser memory. When you click export, the file is compiled in-memory via Blob/URL.createObjectURL and downloaded directly onto your local machine. Zero data is uploaded or logged.
  • Local Settings & Preferences: Stored locally on your device via chrome.storage.local (e.g., preferred delimiter, clean number toggle, Excel BOM preference). This data never leaves your browser.
  • License Verification: If you purchase SheetPulse Pro, only your Paddle Order/Transaction ID is sent securely via TLS 1.3 to our cloud entitlement gateway to verify pro activation status. No personal financial details or card numbers are ever handled by the extension.

3. Browser Permissions Usage

  • activeTab: Used strictly when you open the popup or click "Extract Table" to inspect the current active webpage's DOM for tables.
  • storage: Used solely to store your export preferences, 7-day trial start date, and license key locally.
  • contextMenus: Used to provide the right-click "Extract Table with SheetPulse" shortcut.

4. Third-Party Services

Payments are processed exclusively by Paddle.com Market Ltd, our Merchant of Record. When making a purchase, your payment transaction is governed by Paddle's Privacy Policy. We do not store or process credit card details.

5. Compliance with Developer Policies

SheetPulse complies fully with the Google Chrome Web Store Single Purpose and User Data Policies, and the Microsoft Edge Add-ons Developer Program Policies. SheetPulse does not contain trackers, telemetry beacons, background scrapers, or advertising cookies.
